Problem Easy · 10 pts

Two Sum

Given an array nums and an integer target, return the indices of the two numbers that add up to target.

Each input has exactly one solution, and you can't use the same element twice.

Example 1
Input  2 7 11 15 / 9
Output 0 1
Input  3 2 4 / 6
Output 1 2
solution.py
Python 3↺ Reset
def two_sum(nums, target): seen = {} for i, n in enumerate(nums): need = target - n if need in seen: return seen[need], i seen[n] = i # read stdin → print answer nums = list(map(int, input().split())) target = int(input()) print(*two_sum(nums, target))

From the first draft
to the final grade.

Each step of a lab happens in one tool: writing code, running it, grading it and reviewing it. Students stay in their editor. Professors stay in their dashboard.

01 / Write

An IDE built for labs

Monaco editor with the problem statement next to it. Drafts are saved for each question, so a refresh won't lose your work.

/problems/[lab]/[question]
02 / Run

Run before you submit

Run your code against the sample inputs or your own. You see expected and actual output for each test, side by side.

Run · sample input
03 / Submit

Graded in isolation

Each submission runs against every test case, hidden ones included, in its own sandboxed job. Results and progress are saved automatically.

Submit · all test cases
04 / Track

Progress you can see

Streaks, rank, and solved counts split into Easy, Medium and Hard, plus suggestions for what to try next.

/progress
05 / Author

Write challenges, not scripts

Title, Markdown description, difficulty and points. Upload input and output files as test pairs, and mark each one as a public sample or hidden.

/admin/labs/[lab]/create-question
06 / Review

Analytics for every student

A leaderboard you can filter by lab, with progress, score and last active time. Open any student to see their full submission history.

/admin/Analytics/[student]
